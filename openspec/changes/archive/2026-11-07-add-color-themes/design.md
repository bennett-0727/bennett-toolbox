# Design

## Context

现有主题由 `html[data-theme]` 驱动，`src/theme.ts` 维护 `Theme` 联合类型与 `bennett-theme` 持久化，`src/styles/glass.css` 通过变量与 `html[data-theme="glass-light"]` 覆盖块实现深浅两套玻璃。深色基础层中大量主色以硬编码形式出现：`rgba(10, 132, 255, …)` 约 57 处、`rgba(191, 90, 242, …)` 约 18 处、`rgba(48, 209, 188, …)` 约 9 处，另有少量 `#0a84ff` / `#64d2ff`。设置页主题网格为两列，e2e 通过 `.theme-option` 序号和 `data-theme` 断言主题。

## Goals / Non-Goals

**Goals:**

- 新增三套深色彩色玻璃皮肤，与现有深浅主题共存，切换与持久化行为一致。
- 以最小改动实现整站换色，不复制整套组件样式。
- 保持既有主题选项顺序与持久化值兼容。

**Non-Goals:**

- 不新增浅色彩色皮肤，不提供用户自定义取色器。
- 不重写 `global.css`（其样式基本已被 `glass.css` 覆盖），仅处理 `glass.css` 中实际生效的主色。
- 不改变玻璃配方的模糊、透明度、边框与高光参数。

## Decisions

### 1. 主题标识与顺序

新增 `glass-aurora`（极光紫）、`glass-ocean`（深海青）、`glass-sunset`（落日橙），追加在 `glass-dark`、`glass-light` 之后。顺序固定为：深色玻璃 → 浅色玻璃 → 极光紫 → 深海青 → 落日橙。

- 理由：e2e 与用户习惯依赖 `glass-dark` 为索引 0、`glass-light` 为索引 1；追加可避免破坏现有断言与已有 localStorage 值。
- 备选：改用 `aurora` 等短标识。弃用原因是与现有 `glass-` 前缀不一致，且无法从值直接看出属于玻璃主题族。

### 2. 主色令牌化

在 `:root` 增加 RGB 三元组令牌，便于以任意透明度复用：

- `--accent-rgb: 10, 132, 255`（主色）
- `--accent-2-rgb: 191, 90, 242`（辅助色）
- `--accent-3-rgb: 48, 209, 188`（点缀色）

将 `glass.css` 中对应 `rgba(...)` 硬编码替换为 `rgba(var(--accent-rgb), α)` 等形式，并把 `#0a84ff`、`#64d2ff` 等主色替换为 `var(--primary-color)` / `var(--primary-light)`。彩色皮肤通过 `html[data-theme="…"]` 覆盖三组 RGB 令牌与 `--primary-*`，即可让导航、按钮、进度条、焦点、光晕与背景渐变整体换色。

- 理由：避免为每套皮肤复制数十条组件规则；新增皮肤只需一组变量。
- 备选：为每套皮肤编写完整覆盖块。弃用原因是重复量大、后续组件新增时容易漏配。
- 备选：CSS `color-mix()`。弃用原因是 Electron 28 的 Chromium 版本与现有代码风格更适合直接 RGB 变量。

### 3. 配色取值

| 主题 | 主色 | 辅助色 | 点缀色 | 背景基调 |
| --- | --- | --- | --- | --- |
| `glass-aurora` | `#a855f7` (168,85,247) | `#ec4899` (236,72,153) | `#22d3ee` (34,211,238) | 深紫黑 |
| `glass-ocean` | `#06b6d4` (6,182,212) | `#3b82f6` (59,130,246) | `#10b981` (16,185,129) | 深青黑 |
| `glass-sunset` | `#f97316` (249,115,22) | `#f43f5e` (244,63,94) | `#fbbf24` (251,191,36) | 深棕黑 |

每套皮肤同时覆盖 `--primary-hue`、`--primary-color`、`--primary-light`、`--primary-dark`，并为 `.app` 提供专属的深色基底渐变，使三套皮肤在空态与大面积背景上可区分。`color-scheme` 继承 `:root` 的 `dark`，浅色主题逻辑不受影响。

### 4. 主题预览

主题预览不随当前主题变化，必须展示各选项自身配色。为 `.theme-preview.glass-aurora` 等类名分别定义背景渐变与 `::before` 光晕；`.glass-dark`、`.glass-light` 现有预览保持不变。`theme-options` 由固定两列改为 `repeat(auto-fit, minmax(120px, 1fr))`，五选项在窄卡片中自动换行，在宽卡片中单行铺开。

- 理由：避免预览颜色被当前主题令牌污染，同时保持 DOM/CSS 绘制约束。

### 5. 持久化与回退

`Theme` 联合类型扩展为五个值，`getInitialTheme` 使用支持列表校验；不在列表内的历史值或损坏值回退 `glass-dark`。`applyTheme` 逻辑不变。

### 6. 国际化

设置页外观说明改为「选择玻璃主题或彩色皮肤」，新增「极光紫」「深海青」「落日橙」三个标签，并在 `src/i18n/en.json` 补齐 `Aurora Violet`、`Deep Ocean`、`Sunset Orange` 与说明文案的英文映射，继续保持运行时 DOM 翻译机制不变。

### 7. 测试策略

- `setTheme` 辅助函数改为按 `data-theme` 值定位选项，避免依赖序号。
- 主题测试扩展为：五选项齐全、逐套选择彩色皮肤后 `data-theme` 与激活态正确、重载后恢复、主色计算值随皮肤变化、玻璃表面仍含 `blur`。
- 英文设置页扫描覆盖新增标签；响应式测试覆盖 1000×700 与 1200×760 无横向溢出且英文标签不截断。

## Risks / Trade-offs

- [主色替换遗漏导致个别组件仍为蓝色] → 完成后全量搜索 `10, 132, 255`、`191, 90, 242`、`48, 209, 188` 与主色十六进制，确认 `glass.css` 无残留；e2e 对主按钮与导航激活态取计算样式断言。
- [浅色主题误继承彩色令牌] → 彩色皮肤仅通过 `html[data-theme="glass-*"]` 覆盖，`glass-light` 规则优先级与覆盖块保持不变；回归测试浅色主题配色。
- [五选项在窄区域拥挤或英文换行溢出] → 使用 `auto-fit` 网格并在 1000×700、1200×760 与英文模式做 e2e 溢出检查。
- [彩色背景上文字对比度不足] → 皮肤沿用深色文字令牌（浅色文字、次要文字），主色仅用于强调与光晕；e2e 校验激活文字与背景可读。

## Migration Plan

1. 扩展主题类型与设置页选项，旧值继续有效。
2. 落地 CSS 令牌与三套皮肤覆盖，逐套人工核对主要模块。
3. 更新 i18n、e2e 与文档。
4. 回滚策略：移除新增皮肤变量与选项即可，`bennett-theme` 中的新值在旧版本会回退为 `glass-dark`，不阻塞启动。
