# Spec Delta

## MODIFIED Requirements

### Requirement: 外观设置

设置页 SHALL 提供深色玻璃、浅色玻璃与至少三套彩色皮肤共五个主题选项，选项 MUST 展示对应主题的预览；选择后立即应用并持久化。

#### Scenario: 选择浅色玻璃

- **WHEN** 用户在设置页点击“浅色玻璃”
- **THEN** 页面切换为浅色玻璃主题，选项显示激活状态，重新打开应用后仍为浅色

#### Scenario: 选择彩色皮肤

- **WHEN** 用户在设置页点击“极光紫”“深海青”或“落日橙”
- **THEN** 页面立即切换为该皮肤配色，选项显示激活状态，重新打开应用后仍为该皮肤

#### Scenario: 主题预览完整

- **WHEN** 设置页显示五个主题选项
- **THEN** 每个选项包含可见且符合自身配色的界面预览，预览不得塌缩为空白或仅剩边框

## ADDED Requirements

### Requirement: 主题选项响应式布局

五个主题选项 MUST 在设置页以网格排列，在 1000×700 与 1200×760 窗口下不得产生横向溢出，英文标签不得被截断。

#### Scenario: 窄窗口主题选项

- **WHEN** 窗口为 1000×700 且打开设置页
- **THEN** 主题选项自动换行排列，页面与主区域无横向滚动，所有标签完整可见

#### Scenario: 英文长标签

- **WHEN** 语言为 English 且窗口为 1200×760
- **THEN** 五个主题选项的英文标签与预览完整显示，不超出选项边框
