# Proposal

## Why

MCP 服务已扩展到 14 个工具，但 README 只有简要列表。用户需要完整的工具参数、返回值、客户端配置、日志与故障排查说明，才能稳定让 AI 调用。

## What Changes

- 新增 `docs/mcp.md`：工具参考、调用示例、客户端配置、操作与安全指南、日志排查、常见问题。
- 在 README 的 MCP 章节链接到完整文档。
- 不修改 MCP 服务行为、参数或依赖。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。本次为纯文档变更。

## Impact

- 新增：`docs/mcp.md`
- 修改：`README.md`（增加文档链接）
