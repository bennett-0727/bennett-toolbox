# Proposal

## Why

插件化后应用需要更接近 Codex 桌面端的工作区布局：侧栏常驻、主画布展示当前工具、顶部与底部状态栏固定；设置与插件管理不应整页替换主画布。默认进入工作台，不自动加载插件。

## What Changes

- 应用布局改为侧栏 + 主画布：顶部当前工具栏、可滚动内容区、底部状态栏。
- 默认工作台，不自动打开首个插件；工具从侧栏或工作台打开，占满主画布。
- 设置改为右侧抽屉浮层，不替换主画布；插件管理保留在工作台。
- 工作台提供安装/卸载/停用/打开插件，默认不预装。
- 更新相关测试与截图。

## Capabilities

### Modified Capabilities

- `settings-page`: 设置以抽屉呈现，工作台保持可见。
- `plugin-settings`: 管理入口移到工作台。
- `responsive-layout`: 顶栏/底栏/抽屉在窄窗口无溢出。
