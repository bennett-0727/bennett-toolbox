# Design

## Context

问题集中来自全局样式与最小窗口 1000×700 的边界：多处按钮用单字中文充当图标；全局 input focus 同时使用 outline、border、box-shadow；侧边栏在 700 高度下高度不足；图片转换控制区断点为 900px，低于应用最小宽度，导致三列布局被压缩；设置页在 700 高度下内容超出首屏。

## Goals / Non-Goals

**Goals:**

- 消除重复文字和多重焦点框。
- 让最小窗口下的侧边栏、图片转换控制区、设置页完整、可读。
- 禁用态与可点击态有明确视觉差异。

**Non-Goals:**

- 不重做整体视觉风格或导航结构。
- 不改变任何转换/搜索/取色逻辑。
- 不调整 1200px 以上宽度的图片转换三列布局。

## Decisions

### 图标使用系统 emoji

沿用现有 JSON/图片模块的 emoji 图标风格，替换文档、PDF、视频、去水印的单字图标。相比引入 SVG 组件，改动更小且与现有按钮一致；emoji 不属于需要翻译的中文文本，英文扫描不会再出现重复。

### 焦点只保留一个视觉环

对 input/textarea/select 移除全局 `:focus-visible` outline，保留组件自身的边框与柔和阴影。JSON 输入是全出血 textarea，额外移除其边框，用 `.input-panel:focus-within .panel-header` 的下划线表示焦点，避免蓝线贴到面板分隔处。搜索框保留单一边框 + 2px 低透明光晕。

### 禁用主按钮中性化

`.btn-primary:disabled` 改为半透明灰玻璃并去除蓝色阴影，避免“不可用但看起来最醒目”。

### 短窗口使用高度媒体查询

在 `max-height: 760px` 下压缩侧边栏导航内边距、隐藏拖拽提示，并收紧设置卡片间距与预览高度；在 `max-width: 1180px` 下将图片转换控制区切换为单列，避免格式按钮孤立换行。

## Risks / Trade-offs

- [隐藏拖拽提示可能降低可发现性] → 仅在 760px 以下隐藏，用户仍可拖拽，正常窗口保留提示。
- [单列控制区增加纵向高度] → 通过滚动承载，换取格式与按钮不再挤压。
- [移除输入 outline 可能影响键盘可访问性] → 仍保留边框/光晕或标题栏下划线作为焦点提示。
