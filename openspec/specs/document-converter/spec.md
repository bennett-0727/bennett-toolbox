# document-converter Specification

## Purpose
定义文档转 Markdown 在用户通过按钮选择或拖拽文件时的类型校验、错误提示与可转换状态，确保不支持的文件不会进入转换流程。

## Requirements

### Requirement: 选择文件必须校验支持的类型

用户通过“选择文件”按钮或拖拽选择文件时，系统 SHALL 校验文件扩展名；不在支持列表内的文件 MUST 被拒绝，并显示明确的错误提示，不得进入转换流程。

#### Scenario: 通过按钮选择不支持的文件

- **WHEN** 用户通过“选择文件”按钮选择后缀为 `xyz` 的文件
- **THEN** 界面显示“暂不支持此文件类型”错误，且不显示文件摘要、不启用转换

#### Scenario: 通过拖拽选择不支持的文件

- **WHEN** 用户拖入后缀为 `xyz` 的文件
- **THEN** 界面显示“暂不支持此文件类型”错误，且不显示文件摘要

#### Scenario: 选择支持的文件

- **WHEN** 用户选择后缀为 `txt` 的文件
- **THEN** 界面显示文件摘要，转换按钮可用
