# file-search Specification

## Purpose
定义文件搜索在搜索目录不可用、权限不足时的错误反馈与容错行为，避免用户把目录错误误判为没有匹配结果，同时保证单个子目录异常不会中断整体搜索。

## Requirements

### Requirement: 根目录不可读时必须提示错误

当搜索根目录不存在或不可读取时，系统 MUST 显示错误提示，并 MUST NOT 静默返回空结果。

#### Scenario: 搜索目录不存在

- **WHEN** 用户选择不存在的目录并输入关键词
- **THEN** 界面显示包含“搜索失败”的错误提示，结果列表为空

#### Scenario: 恢复有效目录

- **WHEN** 用户把搜索目录改为有效目录并输入存在的文件名
- **THEN** 错误提示消失，结果列表显示匹配文件

### Requirement: 子目录错误不中断搜索

搜索过程中单个子目录不可读取时，系统 SHALL 跳过该子目录并继续搜索其他目录。

#### Scenario: 子目录无权限

- **WHEN** 根目录可读但某个子目录不可读
- **THEN** 搜索继续执行，其他目录的匹配结果正常返回
